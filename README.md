              # Inventory Management System
       
       > نظام احترافي لإدارة المخزون متعدد الشركات والفروع والمستودعات وطلبات النقل.
       
       ---
       
       ## 📋 عن المشروع
       
       Inventory Management System هو نظام ويب لإدارة المخزون والعمليات المرتبطة به، مصمم للشركات والمؤسسات التي تحتاج إلى إدارة المنتجات والمخزون عبر عدة فروع ومستودعات من خلال منصة مركزية.
       
       يهدف النظام إلى تسهيل إدارة:
       
       - المنتجات
       - المخزون
       - الفروع
       - المستودعات
       - طلبات النقل
       - المستخدمين
       - الأدوار والصلاحيات
       - العمليات التشغيلية
       - البيانات الخاصة بكل شركة
       
       النظام مبني باستخدام تقنيات ويب حديثة وقابل للتوسع مستقبلًا ليشمل المحاسبة والتقارير والتحليلات المتقدمة.
       
       ---
       
       # 🎯 أهداف النظام
       
       يهدف النظام إلى:
       
       1. توحيد إدارة المخزون في منصة واحدة.
       2. تقليل الأخطاء اليدوية.
       3. تسهيل نقل المنتجات بين المواقع.
       4. تحسين متابعة المخزون.
       5. التحكم في صلاحيات المستخدمين.
       6. فصل بيانات الشركات والفروع.
       7. توفير لوحة تحكم واضحة للإدارة.
       8. بناء أساس تقني قابل للتوسع.
       9. تحسين دقة العمليات التشغيلية.
       10. توفير سجل مركزي للعمليات.
       
       ---
       
       # ✨ المزايا الرئيسية
       
       ## 📦 إدارة المنتجات
       
       - إضافة المنتجات.
       - تعديل المنتجات.
       - عرض المنتجات.
       - البحث عن المنتجات.
       - تفعيل وتعطيل المنتجات.
       - تنظيم بيانات المنتجات.
       - ربط المنتجات بالمخزون.
       - دعم التوسع مستقبلًا لإضافة SKU وBarcode.
       
       ---
       
       ## 🏢 إدارة الفروع
       
       يسمح النظام بإدارة فروع المؤسسة ومتابعة العمليات المرتبطة بكل فرع.
       
       يشمل ذلك:
       
       - إنشاء الفروع.
       - تعديل الفروع.
       - تفعيل وتعطيل الفروع.
       - ربط المستخدمين بالفروع.
       - استخدام الفروع في عمليات النقل.
       - عزل بيانات الفروع حسب صلاحيات المستخدم.
       
       ---
       
       ## 🏭 إدارة المستودعات
       
       يدعم النظام إدارة المستودعات كمواقع مستقلة داخل المؤسسة.
       
       يمكن استخدام المستودعات في:
       
       - تخزين المنتجات.
       - استقبال المنتجات.
       - إرسال المنتجات.
       - عمليات النقل.
       - متابعة المخزون.
       - إدارة عمليات الاستلام والصرف.
       
       ---
       
       # 📊 إدارة المخزون
       
       يوفر النظام أساسًا لإدارة المخزون حسب الموقع.
       
       يشمل النظام حاليًا البنية اللازمة للتوسع في:
       
       - الكميات المتوفرة.
       - المنتجات منخفضة المخزون.
       - المنتجات النافدة.
       - حركات المخزون.
       - عمليات الاستلام.
       - عمليات الصرف.
       - عمليات التحويل.
       - الجرد.
       - التسويات.
       - سجل حركة المنتجات.
       
       ---
       
       # 🔄 طلبات نقل المخزون
       
       تعتبر طلبات النقل من الوظائف الأساسية في النظام.
       
       تسمح للمستخدم بإنشاء طلب لنقل المنتجات أو المخزون من موقع إلى موقع آخر.
       
       أمثلة:
       
       ```text
       المستودع الرئيسي
              ↓
            نقل
              ↓
       الفرع
